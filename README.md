# KIPS (Kernel-level Intrusion Prevention System) v1.1

**KIPS** — это легковесная система предотвращения вторжений (IPS) для операционных систем семейства Linux, предназначенная для защиты рабочих станций от несанкционированного подключения USB-устройств (флеш-накопителей, BadUSB, аппаратных кейлоггеров).

## 🚀 Как это работает
Программа работает в фоновом режиме как системный демон (`systemd`). Она в реальном времени перехватывает ядерные события подсистемы `udev`. 
При обнаружении нового USB-устройства KIPS проверяет его серийный номер по динамическому белому списку.
Если устройство не опознано, система мгновенно выполняет логическую отвязку драйвера (`unbind`) на уровне ядра через `sysfs`, полностью изолируя порт.


## 📋 Функционал (Что софт умеет делать)

* **⚙️ Автоматический режим Демона:** Непрерывный мониторинг состояния USB в реальном времени. Работает полностью в фоне через `systemd`, запускается автоматически при старте системы (еще до ввода пароля пользователя).
* **🧠 Ядерный перехват (Udev Interception):** Прямое чтение событий из подсистемы ядра Linux (`udev`) в обход высокоуровневых интерфейсов. KIPS видит устройство в ту же миллисекунду, как внутри порта пошел ток.
* **⚡ Активная защита (USB Unbind IPS):** При обнаружении угрозы KIPS мгновенно отправляет команду отвязки драйвера (`unbind`) в виртуальную файловую систему ядра `sysfs`. Опасное устройство обесточивается на логическом уровне до того, как успеет навредить.
* **🔒 Интеллектуальный белый список:** Автоматическое сканирование системы в момент установки. KIPS сам находит твою рабочую мышь, клавиатуру и вебкамеру, заносит их в базу и не трогает при работе, защищая от случайных блокировок.
* **📝 Централизованный аудит:** Запись всех событий, алертов и успешных блокировок в выделенный системный лог `/var/log/kips.log` с точностью до секунды.
* **🧹 Полный жизненный цикл:** Удобный инсталлятор (`install.sh`) и умный деинсталлятор (`uninstall.sh`), который полностью вычищает софт одной командой `sudo kips-uninstall`.

## 🛠️ Установка и управление

**1. Клонировать репозиторий и запустить установку:**
# Скачиваем проект с вашего гитхаба
```bash
git clone https://github.com/irzwiqqk/kips.git
```
# Переходим в папку проекта
```bash
cd kips
```
# Даем права и запускаем установщик
```bash
chmod +x install.sh
sudo ./install.sh
```
Мониторинг логов в реальном времени:
```Bash
sudo tail -f /var/log/kips.log
```
Полное удаление программы из системы:
```Bash
sudo kips-uninstall
```
